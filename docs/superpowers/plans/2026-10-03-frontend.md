# Workdesk Agent Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a usable Vite frontend around the existing Blender office and a local agent workflow demo.

**Architecture:** React components own layout and selection. A pure workflow reducer owns demo transitions; one React timer advances running phases. React Three Fiber renders the existing GLB, with accessible HTML roster controls and a preview fallback.

**Tech Stack:** Vite, React, TypeScript, Three.js, React Three Fiber, Drei, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-03-frontend-design.md`

## Global Constraints

- Use local demo data; do not imply real agent connections.
- Use existing `assets/3d/office.glb` through Vite asset URLs.
- Keep six roles: Lead, Backend, Frontend, QA, DevOps, Security.
- No backend, login, publishing, or commit/push.
- Run the production build once after the complete task; do not launch iOS simulators.

## Review Focus

- Pause during an active phase: timer ticks must not advance paused state.
- Replay after completion: begin a fresh run without stale history or duplicate timers.
- Reset while running: return to idle and clear activity.
- Model or WebGL failure: show preview while keeping roster and workflow usable.
- Narrow viewport and keyboard input: panels fit and selection remains available without canvas interaction.

### Task 1: Demo workflow and Vite foundation

**Files:** `package.json`, `index.html`, `vite.config.ts`, `tsconfig.json`, `.gitignore`, `src/demo.ts`, `src/demo.test.ts`, `src/main.tsx`.

**Interfaces:** Export `roles`, `initialState`, and `demoReducer(state, action)` from `src/demo.ts`. Actions are `start`, `tick`, `pause`, `resume`, and `reset`. State contains phase index, run status (`idle`, `running`, `paused`, `completed`), and bounded activity entries. Export `getAgentStatus(role, state)` for rendering.
